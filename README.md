 QR Code Scanner & Generator App
🎯 Проект для сканирования и генерации QR-кодов на Android с использованием Expo
___________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________
Этот тестовый проект демонстрирует функциональность приложения для сканирования и генерации QR-кодов на Android с использованием Expo. Проект включает два основных раздела: сканирование QR-кодов и генерация их для различных типов данных (например, для URL, электронной почты и т.д.).
Проект предназначен для демонстрации базовых возможностей работы с QR-кодами в мобильных приложениях, а также как их интегрировать с использованием React Native и Expo.
___________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________
🚀 Возможности приложения:
Сканирование QR-кодов: Приложение позволяет пользователю сканировать QR-коды с помощью камеры устройства.
Генерация QR-кодов: Позволяет генерировать QR-коды для текстовых данных, включая URL и email.

📦 Как скачать и запустить:
Скачай проект:
1)Для начала скачай репозиторий с помощью Git:
```
git clone https://github.com/12ed3e34dw/Scanner_expo.git
```
2)Установи зависимости:
Перейди в директорию проекта и установи необходимые зависимости:
```
cd Scanner_expo
npm install
```
3)Установи зависимости:
Перейди в директорию проекта и установи необходимые зависимости:
```
expo start
```
